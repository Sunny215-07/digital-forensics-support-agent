# Digital Forensics Support Agent

> Week 0 Initial Concept

## 1. Project Background

我從以前就對鑑識領域很有興趣，而目前就讀的領域與資訊科技相關，因此在思考 AI Agent 的應用方向時，我聯想到「數位鑑識」這個主題。希望能透過這次自主學習，在學習 AI Agent 的同時，也進一步探索自己感興趣的數位鑑識領域。

## 2. Problem I Want to Explore

隨著科技進步，我開始思考是否能透過 AI Agent 的協助，整理不同時間點的資訊變化，並比較這些變化在時間上的關聯，從中找出可能值得進一步注意的線索，提供數位鑑識專業人員進一步判斷，而不是直接由 AI 判定事件事實。

## 3. Target User

本產品的主要使用者設定為數位鑑識專業人員。我認為 AI Agent 所整理出的資訊與可能關聯，仍需要具備專業知識的人員判斷其結果是否合理、是否值得進一步檢視。因此 AI Agent 的角色是提供輔助，而不是取代專業人員做出最終判斷。

## 4. Product Concept

我希望這個產品能夠整理不同時間點的數位資訊，比較資訊內容在不同時間之間產生的變化，並將這些變化整理後呈現給數位鑑識專業人員，作為進一步分析與判斷的參考。

## 5. Support Agent Concept

在產品的使用過程中，我希望加入客服 Agent，協助數位鑑識專業人員理解系統所產生的結果。

目前主要希望處理兩種問題：

1. 當某些資料沒有被系統整理出來時，協助使用者了解可能的原因。
2. 當系統將某項資訊標記為「值得注意」時，協助使用者理解系統產生這項標記的依據。

客服 Agent 的角色主要是解釋產品的處理結果，而不是替數位鑑識專業人員進行最終判斷。

## 6. Example Use Cases

### Use Case 1

使用者發現某項資料沒有出現在系統整理的結果中，因此詢問客服 Agent，希望了解系統為什麼沒有整理出這項資料。

### Use Case 2

使用者發現某項資訊被系統標記為「值得注意」，因此詢問客服 Agent。Agent 協助說明系統產生此標記的依據，讓使用者決定是否需要進一步檢視。

## 7. Agent Boundary

Agent 可以協助解釋系統為什麼產生某個結果，但不能將系統發現的時間關聯或資訊變化直接描述為案件事實或因果關係。

最終的分析與判斷仍應由數位鑑識專業人員完成。

## 8. Current Questions

目前這個構想仍處於初步探索階段，我還想進一步了解：

- 在真實的數位鑑識工作中，時間軸整理的需求有多重要？
- 現有的數位鑑識產品是否已經具有類似的功能？
- AI Agent 要如何知道產品為什麼將某項資訊標記為「值得注意」？
- 如何避免 Agent 將「可能的關聯」描述成「確定的事實」？
